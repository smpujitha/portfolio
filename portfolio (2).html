RFM customer segmentation

Segmentation
Python pandas NumPy scikit-learn

Problem

Treating every customer the same wastes retention effort. The business needed to know who its best customers are and who is about to leave.

Process

Cleaned transaction data, calculated Recency, Frequency and Monetary value for each customer, and grouped customers into segments by buying behaviour.

Result

Separate high-value and at-risk customer groups, so retention offers can be targeted at the right people.

Credit card fraud detection

Classification
Python pandas scikit-learn Matplotlib

Problem

Fraudulent transactions are very rare, so a model can look accurate while missing nearly all of them.

Process

Explored transaction data, addressed heavy class imbalance, trained a classification model and evaluated it with imbalance-appropriate metrics.

Result

A classifier that flags potentially fraudulent transactions for review instead of relying on overall accuracy.
